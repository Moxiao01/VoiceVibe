# 语音输入工具「Voice Vibe」实现计划

参考 OpenLess（Rust+Tauri 的开源语音输入工具，四种输出模式：原始转写/轻量清理/结构化提示词/正式文本）与蛐蛐 QuQu（本地 FunASR + LLM 润色）的思路，用 Python 实现一个 Windows 桌面语音输入工具：**按住热键说话 → 松开后自动润色 → 文字插入当前光标处**。

## 一、技术选型（已确认）

| 模块 | 方案 |
|---|---|
| ASR 识别 | 云端流式 API：阿里云百炼 DashScope Paraformer 实时语音识别（WebSocket 流式、自带中文标点、按秒计费很便宜）。代码做引擎抽象接口，后续可换/加其他云端或本地引擎 |
| LLM 润色 | OpenAI 兼容接口（配置 base_url + api_key + model），兼容智谱 GLM / 通义 / Kimi / OpenAI / Ollama 等 |
| 技术栈 | Python 3.10+，PyQt6 悬浮条 + 托盘 |
| 文字注入 | 剪贴板暂存 → 模拟 Ctrl+V → 恢复原剪贴板内容 |

依赖：`PyQt6`、`sounddevice`、`numpy`、`dashscope`、`openai`、`keyboard`、`pyperclip`、`tomli`（3.11+ 用内置 tomllib）。

## 三、核心流程

1. **按住热键**（默认 F2，可配置）→ 采集麦克风 PCM → 实时推送 ASR WebSocket → 悬浮条实时显示流式中间文字
2. **松开热键** → 得到最终转写 → 按当前模式处理：
   - **原始转写**（F4）：直接上屏
   - **简单润色**（F2，默认）：规则清理语气词（嗯/啊/呃/那个/就是说等，句首删除、句中酌情）、折叠重复字词、整理空格标点——本地瞬时完成
   - **深度润色 / Prompt 化**（F3）：调用 LLM，用提示词工程把口述内容重写为结构化 AI 提示词（`# 角色 / # 任务 / # 背景 / # 约束 / # 输出格式`），保留全部关键信息、不编造；悬浮条显示"润色中…"，失败自动降级为简单润色结果并提示
3. **注入**：结果写入剪贴板 → 模拟 Ctrl+V 插入任意应用光标处 → 恢复剪贴板
4. **记录**：原始转写、润色结果、模式、时间戳写入 history.jsonl，托盘菜单可打开查看
5. **保护逻辑**：录音短于 300ms 忽略；Esc 取消本次输入；LLM 超时/断网降级提示

## 四、深度润色提示词工程（prompts.py）

系统提示词要点：角色 = 资深 Prompt 工程师；任务 = 把口语化、跳跃的口述内容重写为可直接发给 AI 的提示词；要求 = 提炼真实意图、补全结构（角色/任务/约束/输出格式）、保留所有事实细节与技术术语（中英混排不翻译）、禁止编造、只输出提示词本身；temperature 0.3。模板与输出模式一一对应，方便后续加"正式文本"等模式。

## 五、实现步骤（里程碑）

1. **骨架**：项目结构 + config + 悬浮条显示录音状态 + 全局热键按住/松开 + 录音采集
2. **识别打通**：DashScope 流式 ASR 接入，partial/final 实时上悬浮条（需你在 config.toml 填 DashScope API Key）
3. **上屏**：剪贴板 + Ctrl+V 注入与剪贴板恢复
4. **简单润色**：语气词规则引擎 + 单元测试
5. **深度润色**：OpenAI 兼容 LLM 客户端 + 提示词模板 + 降级逻辑（需填 LLM API Key）
6. **收尾**：历史记录、托盘设置界面、README、异常兜底；可选 pyinstaller 打包说明

## 六、需要你配合的两件事

- 实现到第 2 步时需要提供**阿里云百炼（DashScope）API Key**（实时识别有免费额度，bailian.console.aliyun.com 开通）
- 实现到第 5 步时提供**任一 OpenAI 兼容的大模型 Key**（智谱/通义/Kimi 等）作为深度润色引擎
